## 🧠 Overview

FabFilter Pro-Q is a Windows plug-in suite.

The archive in this repository contains the plug-in suite itself plus the runtime components required for the first launch.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎨 Chain Processing | Modules are arranged in series and reordered in the chain. |
| 🎬 Spectrum Tools | Frequency-dependent work is done with visual feedback. |
| 📐 Offline Rendering | Processing runs faster than real time on selected material. |
| 🛠️ Preset Recall | Settings are stored per project and as user presets. |
| 🧠 Metering | Level and dynamics meters show what the chain does to the signal. |

## Additional Information for Windows Users

Hardware headroom matters more than the minimum list suggests: previews and batch jobs scale with RAM and VRAM, not with CPU clocks alone.

A slow first launch is usually the one-time runtime registration; later starts skip that step.
